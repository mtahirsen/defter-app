# Defter — tanıtım sayfası

[Defter](https://mtahirsen.github.io/defter-app/), Claude Code sohbetlerini arayıp tek tuşla terminalde devam ettiren
ücretsiz bir macOS uygulaması. İndirme: [Releases](https://github.com/mtahirsen/defter-app/releases/latest).

Bu repo yalnızca tanıtım sayfasını (`index.html` + `assets/`) ve sürüm dosyalarını içerir. Ekran görüntüleri
uygulamanın demo modundan, uydurma sohbetlerle alınmıştır.
